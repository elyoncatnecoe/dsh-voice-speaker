# 语音朗读（Voice speaker）

给 DeepSeek Harness 加语音朗读：输入框旁的喇叭读最新回复；**每条助手回复的动作条里也有一个喇叭**，任意一条（含旧消息）都能单独生成语音。播放走流式 PCM，边收边播、首帧即出声、随时可停。

## 能做什么

- **输入框旁喇叭**：读最新一条助手回复。
- **每条消息喇叭**：助手回复动作行里的 🔊，单独朗读/停止任意一条。
- **可视化音色面板**（点 ▾）：
  - **海星**（stella，官方女声原声）· **暗潮**（tide，官方男声原声）
  - **正太**（海星 +0.5 半音）· **萝莉**（海星 +2 半音）· **中性**（海星 −3 半音）
  - **少年**（暗潮 +3 半音）· **大叔**（暗潮 −2 半音）
- **自由微调滑块**：±6 半音，只作用于播放。
- **开关**：面板里关闭后，输入框旁只留一个小 ▾（设置入口不丢）；也可在「插件」里停用整个插件。

## 细节

- **只读正文**：只朗读助手回复正文（`kind:'text'` 块），**跳过思考/推理（`reasoning`）与工具调用**。
- **流式播放**：请求 `format=pcm`（24kHz/16bit/单声道），Host 把上游音频流原样转发，浏览器边收边用 Web Audio 排程播放；点击停止会立即中止请求并掐断所有已排程音频。
- **主题跟随**：按钮与面板用 DSH 主题变量（`--dsw-alias-*`），深浅色自动适配；图标与原生消息操作按钮一致。

## 计费与隐私

- 音频由本机 Host 用你的 `DEEPSEEK_API_KEY` 请求 `https://api.deepseek.com/v1/tools/tts` 生成，**按字符计费**（汉字算 2 字符，1 万字符 3 元，限时 5 折）。
- **变声与播放不产生任何 API 调用、不额外计费**；变调在本机浏览器做，不落文件。
- 密钥只在本机 Host 进程内读取，不经浏览器。

## 已知限制

- 官方只有两个音色（海星 / 暗潮），其余是音高变调模拟，极端参数会失真（建议 ±6 半音内）。
- 变调会带着共振峰一起移动，是"同一个声音变高变低"，不是真正换人声。
- 单条正文超过 5000 字符会被拒读，需分段。
